# ResQSpace 🌊

**AI-Powered Satellite Flood Mapping and Disaster Response Dashboard**

ResQSpace is a hackathon project that uses satellite imagery and geospatial analysis to identify potential flood-affected areas, assess nearby infrastructure exposure, and highlight settlements that may be disconnected from road networks.

## Problem Statement

Floods can damage roads and infrastructure, making it difficult for emergency responders to identify affected areas and reach isolated communities.

## Our Solution

ResQSpace aims to:

- Map potential flood-affected areas using satellite imagery.
- Identify potentially affected roads, bridges, and buildings.
- Analyze road connectivity to highlight potentially isolated settlements.
- Generate a concise situation report to support disaster-response planning.

## Technology Stack

- Frontend: React.js
- Backend: Node.js and Express.js
- Satellite and geospatial processing: Python
- Database: MongoDB (if needed)

## Project Status

🚧 Under development for the Multimodal AI Hackathon 2026.

## Data Sources

The project plans to use Copernicus Sentinel satellite data, Copernicus DEM, and pre-event OpenStreetMap data, with appropriate attribution.

## Disclaimer

ResQSpace is an educational prototype. Its outputs are estimates and should not be treated as verified damage assessments or used as the sole basis for emergency decisions.
