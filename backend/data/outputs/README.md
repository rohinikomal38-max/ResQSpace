# ResQSpace Analysis Outputs

This directory stores generated flood-mapping, infrastructure-exposure, and road-connectivity outputs.

Expected files:
- flood_extent.geojson — generated by the flood-mapping workflow
- infrastructure_exposure.geojson
- infrastructure_summary.json
- road_connectivity.geojson
- connectivity_summary.json

Outputs must be generated by the analysis pipeline. Do not add fabricated result data.
